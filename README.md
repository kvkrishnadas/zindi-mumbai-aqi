# Zindi Google Mumbai Air Quality Challenge — Private LB Rank 28 Solution

A clean, reproducible, **100% open-source (no AutoML)** modular Python pipeline for hourly PM2.5 forecasting across four fixed CPCB/IITM/BMC monitoring stations in Mumbai, India.

## Key Engineering & Domain Highlights

1. **Forensic Data Scrubbing (`src/cleaning.py`)**
   - **Stage 1 (Hardware Sentinels):** Removes CPCB BAM hardware error codes (`flag_high_1000 == 1`, `pm25 > 450.0`) and post-reboot zero dropouts (`pm25 < 2.0`), scrubbing 1,092 corrupted rows out of 48,400.
   - **Stage 2 (Spatial Anomalies):** Scrubs isolated single-station spikes (`pm25 > 240.0` and `> 3.5x` concurrent Mumbai city median), safely stabilized with auxiliary stations (`Other_Mumbai_Stations_2025_2026`) without introducing train-vs-test covariate shift.
   - **2024 Historical Alignment:** Ceils sub-hourly (`:30:00`) timestamps to top-of-hour (`:00:00`), enforces exact `station_name` matching (Trap 1) and verified site IDs (`site_5113`, `site_5102`, `site_5960`, `site_5961`, Trap 2), and applies per-station-hour Median-IQR calibration. `Legacy_Observations_2020_2022` is explicitly excluded.

2. **Gap-Safe, Physics-Informed Feature Factory (`src/features.py`)**
   - **Zero Row-Index `.shift()` Calls:** Uses $O(\log N)$ calendar timestamp slicing (`np.searchsorted`) so the 5-day withheld gap (`Oct 24-28`) never leaks stale observations.
   - **Post-Diwali Sea-Breeze Calibration:** Clips lookbacks (`clip_cap = 190.0`) so Diwali firework peaks (`Nov 8-9`) do not over-inflate Day +3/+4 Private LB forecasts (`Nov 11-12`), applies two-speed exponential horizon decay (`tau_fast = 30h`, `tau_slow = 120h`), and encodes nocturnal thermal inversion interactions peaking at `04:00 IST`.

3. **Symmetric Multi-Branch Hybrid Ensemble & Horizon-Regime Gating (`src/cv.py`)**
   - Combines **Additive Residual** models (`LightGBM Huber`, `LightGBM L2`, `Scikit-Learn HGB`, `XGBoost`, `CatBoost`) with **Multiplicative Log-Ratio + Duan's Smearing** models (`LightGBM`, `XGBoost`, `CatBoost`).
   - A physics-guided Horizon-Regime Gate routes long-horizon post-hole predictions (`> 64h`) to the Additive branch while routing active winter transitions (`<= 64h`) to the Multiplicative Log-Ratio branch.

## Quick Start (Local VS Code + `uv`)

```bash
# 1. Sync isolated Python 3.12 environment
uv sync

# 2. Activate nbstripout so Jupyter outputs stay local and Git diffs stay clean
uv run nbstripout --install

# 3. Place competition CSVs into data/raw/, then open in VS Code and run:
#    Step A: notebooks/01_eda_audit.ipynb
#    Step B: notebooks/02_modeling_pipeline.ipynb
```
